# Frequently Asked Questions

Quick answers to the most common questions about **Fluent Forms**. If you can't find what you're looking for, see [How to Get Support](/get-support).

## General

### Is Fluent Forms free?

Yes. The core plugin is free and available on the WordPress plugin directory. The [**Pro Add-on**](/upgrade-to-pro-add-on) unlocks premium fields, integrations, payments, conversational forms, and more.

### Do I need to install Fluent Forms before installing the Pro Add-on?

Yes. The Pro Add-on requires the free core plugin to be installed and activated first. See [How to Install Fluent Forms](/install-fluent-forms).

### Can I migrate from Contact Form 7 / WPForms / Gravity Forms?

Yes. Fluent Forms has built-in importers for Contact Form 7, WPForms, Gravity Forms, Ninja Forms, and more. See [Fluent Forms Migrator](/migrator-wpforms-contact-form-7-gravity-forms-ninja-forms-caldera-forms).

### Where is form submission data stored?

All [entries](/managing-entries) are stored in your own WordPress database. Fluent Forms does not send your data to any third-party server.

## Forms & Fields

### How many forms can I create?

Unlimited. There is no cap on forms, fields, or submissions. See [How to Create a Form](/create-a-form) to get started.

### Can I create multi-step forms?

Yes — see [Creating a Multi-Step Form in Fluent Forms](/creating-a-multi-step-form).

### Can I conditionally show or hide fields?

Yes — see [Conditional Logic](/set-up-forms-with-conditional-logic).

[Stripe](/integrate-stripe), [PayPal](/integrate-paypal), [Mollie](/integrate-mollie), [RazorPay](/integrate-razorpay), and [Square](/integrate-square-inline-payment-integration). See the [Payments Overview](/payments-overview) to get started.

### Which email marketing tools are supported?

[Mailchimp](/integrate-mailchimp), [ActiveCampaign](/integrate-activecampaign), [ConvertKit](/integrate-kit-former-convertkit), [MailerLite](/integrate-mailerlite), [Brevo (Sendinblue)](/integrate-brevo-formerly-sendinblue), [GetResponse](/integrate-getresponse), [Constant Contact](/integrate-constant-contact), and 20+ others. See the [Integrations Overview](/integrations-overview) for the full list.

## Troubleshooting

### My form is not sending email notifications

This is almost always a WordPress mail-delivery issue, not a Fluent Forms issue. See [Fluent Forms Not Sending Email Confirmations](/not-sending-email-confirmations). We recommend using [FluentSMTP](https://wordpress.org/plugins/fluent-smtp/) for reliable email delivery.

### I'm getting reCAPTCHA / hCaptcha errors

Check that your site keys are correctly configured. See [Spam Protection with Honeypot and Google reCAPTCHA](/spam-protection-with-honeypot-and-google-recaptcha).
