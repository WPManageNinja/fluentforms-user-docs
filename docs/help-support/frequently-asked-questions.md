# Frequently Asked Questions

Quick answers to the most common questions about **Fluent Forms**. If you can't find what you're looking for, see [How to Get Support](/how-to-get-support).

## General

### Is Fluent Forms free?

Yes. The core plugin is free and available on the WordPress plugin directory. The [**Pro Add-on**](/upgrade-to-fluent-forms-pro-add-on) unlocks premium fields, integrations, payments, conversational forms, and more.

### Do I need to install Fluent Forms before installing the Pro Add-on?

Yes. The Pro Add-on requires the free core plugin to be installed and activated first. See [How to Install Fluent Forms](/how-to-install-fluent-forms).

### Can I migrate from Contact Form 7 / WPForms / Gravity Forms?

Yes. Fluent Forms has built-in importers for Contact Form 7, WPForms, Gravity Forms, Ninja Forms, and more. See [Fluent Forms Migrator](/fluent-forms-migrator-wpforms-contact-form-7-gravity-forms-ninja-forms-caldera-forms).

### Where is form submission data stored?

All [entries](/managing-entries-in-fluent-forms) are stored in your own WordPress database. Fluent Forms does not send your data to any third-party server.

## Forms & Fields

### How many forms can I create?

Unlimited. There is no cap on forms, fields, or submissions. See [How to Create a Form](/how-to-create-a-form-with-fluent-forms) to get started.

### Can I create multi-step forms?

Yes — see [Creating a Multi-Step Form in Fluent Forms](/creating-a-multi-step-form-in-fluent-forms).

### Can I conditionally show or hide fields?

Yes — see [Conditional Logic](/set-up-forms-with-conditional-logic-in-fluent-forms).

## Troubleshooting

### My form is not sending email notifications

This is almost always a WordPress mail-delivery issue, not a Fluent Forms issue. See [Fluent Forms Not Sending Email Confirmations](/fluent-forms-not-sending-email-confirmations). We recommend using [FluentSMTP](https://wordpress.org/plugins/fluent-smtp/) for reliable email delivery.

### I'm getting reCAPTCHA / hCaptcha errors

Check that your site keys are correctly configured. See [Spam Protection with Honeypot and Google reCAPTCHA](/spam-protection-with-honeypot-and-google-recaptcha-in-fluent-forms).

See [How to Get Support](/how-to-get-support).
