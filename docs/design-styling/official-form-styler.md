# Official Form Styler

Fluent Forms is designed to fit any WordPress theme. With the built-in **Form Styler**, you create a custom design that matches your site's branding, with no code. For finer control, you can also apply your own [custom CSS](/stylingcustom-css).

> [!Note]
> **Form Styler** requires **Fluent Forms Pro**. See [Upgrade to Fluent Forms Pro Add-on](/upgrade-to-pro-add-on).

This guide shows you how to style your forms visually.

## Getting Started with Form Styler

Open or create a form and **Save** it. Click **Appearance** in the top bar to open the styling panel. The live preview sits on the left and the style options sit on the right.

![Official Style](/images/design-styling/official-form-styler/official-form-style-01-scaled.webp)

## Styling Options

The styling panel has three tabs: **Elements**, **Message Styling**, and **Import**.

### Elements Tab

The **Elements** tab styles each part of the form. Use **Style Preset** to choose a pre-defined look: **Default**, **Modern (Bold)**, **Modern (Light)**, **Classic**, **Bootstrap Style**, **Clear Blue**, **Forest**, **Plum**, **Night**, **Reef**, **Spark**, or **Inherit Theme Style**.

![Official Form Styler of Fluent Forms step](/images/design-styling/official-form-styler/02-6-scaled.webp)

To customize the look yourself, choose **Custom (Advanced Customization)**. This unlocks the **Label Style**, **Placeholder**, **Inputs & Text Area**, **Radio & Checkbox**, **Submit Button**, and **Container** sections below the presets. Click **Reset** to return to the preset defaults. Click **Export** to download your style and reuse it on another form.

**Label Style:** Open **Label Style** to change the color of the field labels. You can also set typography: font size, font weight, text decoration, line height, and letter spacing.

![General Label](/images/design-styling/official-form-styler/general-label-01-scaled.webp)

**Inputs & Text Area:** Open **Inputs & Text Area** to set the background and text colors of input fields and text areas. You can also change the font size, weight, text decoration, line height, and letter spacing. Set the box shadow of the input and text area boxes below the **Typography** settings.

![Text Area](/images/design-styling/official-form-styler/Text-area-1-scaled.webp)

Switch between the **Normal** and **Focus** tabs to style each state. The **Focus** tab has the same options as the standard styling.

![Input Textarea Fluent Forms](/images/design-styling/official-form-styler/Input-Textarea--scaled.webp)

**Placeholder:** Open **Placeholder** to choose the color of the input field placeholders. You can also set the typography: **Font Size, Font Weights, Text Decoration, Line Height, and Letter Spacing**.

![Placeholder Fluent Forms](/images/design-styling/official-form-styler/Placeholder.webp)

**Radio & Checkbox:** Open **Radio & Checkbox**. When you enable **Smart UI**, you see three styling options for the radio and checkbox fields. Define the border, item, and background colors for the checked state.

To add a **Custom Border**, check **Use Custom Border Style**.

![General Tab Customize Style](/images/design-styling/official-form-styler/Genral-tab-customize-style-1-scaled.webp)

**Image or File Button Style:** Customize the image or file button to match your site’s design. You can set the background color, text color, typography, and border options, and add box shadows.

These options apply to both the **Normal** state and the **Hover** state.

![Or File Button Style](/images/design-styling/official-form-styler/image-or-file-button-style-06-scaled.webp)

**Submit Button:** The default Submit button color is dodger blue. You can change it to match your site's design.

The styling options for the **Submit button** are the same as those for the **Next** and **Previous** buttons in [multi-page forms](/creating-a-multi-step-form). You can set the background color, text color, typography, and border options, and add box shadows.

These options apply to both the **Normal** state and the **Hover** state.

![Button Style Official Form Styler of](/images/design-styling/official-form-styler/Button-Style.webp)

### Container

The **Container** section styles the form container background, padding, and margin.

**Container Style:** Set the background, borders, padding, margin, box shadow, and more.

**Form Border Settings:** Enable the form border and set its type, color, width, and radius.

![Official Form Styler of Fluent Forms step](/images/design-styling/official-form-styler/04-5-scaled.webp)

## Message Styling Tab

The **Message Styling** tab styles the messages your form shows, such as the required asterisk, inline errors, and the messages that appear after a submission. Expand a group to edit it.

**Asterisk Styles:** Choose the color of the asterisk.

![Official Form Styler of Fluent Forms step](/images/design-styling/official-form-styler/05-1-scaled.webp)

**Inline Error Message Styles:** Choose the color of the inline error message. You can also set the typography: font size, font weights, text decoration, line height, and letter spacing.

![Official Form Styler of Fluent Forms step](/images/design-styling/official-form-styler/06-scaled.webp)

**After Submit Success Message Styles:** Customize the message users see after a successful submission. To preview it while you design, fill out your form and submit it.

You can set the background and fonts. You can change the **Font Size** and weight, **Text Decoration**, **Line Height**, and **Letter Spacing**. Set the box shadow of the success message box under the typography settings.

![Official Form Styler of Fluent Forms step](/images/design-styling/official-form-styler/07-scaled.webp)

**After Submit Error Message Styles:** Customize the error message users see after a submission. Its options are the same as the After Submit Success Message Styles.

You can set the background and font colors, font size, weight, text decoration, line height, and letter spacing.

You can also set the box shadow of the success message box and add a **Custom Border** to your form.

![Official Form Styler of Fluent Forms step](/images/design-styling/official-form-styler/08-scaled.webp)

## Import Tab

The **Import** tab lets you select an existing Fluent Forms style or import your own.

Import a style from another **Existing Form**, or **Upload** your Fluent Forms style file.

![Official Form Styler of Fluent Forms step](/images/design-styling/official-form-styler/09.webp)
