# Configuring Your Forms

A great form does more than collect data — it guides people, validates input, and adapts to every answer. **Fluent Forms** gives you control over how each form behaves, from custom messages and access rules to conditional logic and live calculations (Pro). This page lists everything you can configure and links to the right guide.

## Form Settings

Set the rules and messaging that shape the submission experience.

- [Error Messages](/error-message-customization) — customize the validation messages users see.
- [Help Messages](/help-message-customization) — add helpful hints to any field.
- [Restrict Blank Submission](/restrict-blank-form-submission) — stop empty forms from being submitted.
- [Require User Login](/user-login-requirement) — limit a form to logged-in users.
- [Form Restrictions](/form-restrictions-feature) — cap entries, set limits, and control access.
- [Form Scheduling](/form-scheduling-feature) — open and close a form on a schedule.
- [Keyboard Navigation & Shortcuts](/keyboard-navigation-shortcuts) — speed up form building with editor shortcuts.

## Conditional Logic & Dynamic Values

Show the right fields, pre-fill values, and validate input based on context.

- [Conditional Logic](/set-up-forms-with-conditional-logic) — show or hide fields based on user answers.
- [Dynamic Default Value](/dynamic-default-value) — pre-fill fields with dynamic data.
- [Default Value from URL](/set-default-form-value-from-url-parameters) — populate fields from URL parameters.
- [Dynamic Values in Steps](/dynamic-input-values-in-form-steps) — carry values across multi-step forms.
- [Unique Field Validation](/unique-field-validation) — prevent duplicate entries in a field.
- [Step Scroll Offset](/set-scroll-offset-of-form-steps) — fine-tune scrolling between form steps.

## Calculations

Turn inputs into instant results — totals, scores, quotes, and more.

- [Numeric Calculation](/numeric-calculation) (Pro) — calculate values from field inputs in real time.
- [Calculations on Repeat Field](/add-calc-values-on-the-repeat-field) (Pro) — run calculations across repeating rows.
