# User Login Requirement

The **User Login Requirement** feature lets you restrict a form so only logged-in WordPress users can view and submit it. Visitors who are not signed in see a custom message instead of the form.

This guide shows how to enable and customize the login requirement in Fluent Forms.

### Select your form

Open **Forms** from the Fluent Forms navbar and choose the form you want to protect.

![Select form](/images/configuring-forms/form-settings/user-login-requirement/user-login-form-01-scaled.webp)

### Enable login requirement

Go to **Settings & Integrations → Settings → Scheduling & Restrictions**. In **Login Requirement Settings**, turn on **Require user to be logged in**. The same panel also controls [form restrictions](/form-restrictions-feature) and scheduling.

![Login requirement toggle](/images/configuring-forms/form-settings/user-login-requirement/user-login-reqiurement-02-scaled.webp)

### Customize logged-out message

Enter the message shown to visitors who are not logged in.

**For example:** “You must be logged in to access this form. Please log in or register to continue.”

This text helps users sign in or create an account before they can submit the form. To let visitors register from a form, see [How to Create a WordPress User Registration Form](/create-a-wordpress-user-registration-form).

Click **Save Settings** to apply your changes.

![Logged-out user message](/images/configuring-forms/form-settings/user-login-requirement/user-loggin-message-03-scaled.webp)

With **User Login Requirement** enabled, you control who can access each form and give logged-out visitors clear next steps.
