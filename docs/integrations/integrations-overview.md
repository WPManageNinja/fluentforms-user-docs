# Integrations

Your forms work best when they talk to the rest of your stack. **Fluent Forms** connects to the marketing, CRM, automation, and productivity tools you already rely on, so every submission flows exactly where it needs to go. This page rounds up every available integration and links you straight to its setup guide.

> [!Note]
> **Mailchimp** and **Slack** work with the free plugin. **FluentCRM** works when you install the FluentCRM plugin. Most other integrations need **Fluent Forms Pro**. See [Upgrade to Fluent Forms Pro Add-on](/upgrade-to-pro-add-on).

## Duplicate an Integration Feed

Need a second feed with the same settings? Duplicate it instead of rebuilding it.

1. Go to **Forms**, select your form, and click **Configuration** in the top bar.
2. Open **Integrations & Add-ons** in the left menu and click **Integrations**.
3. Find the feed in the list and click the **Copy** icon. The tooltip reads **Duplicate integration feed**.

Fluent Forms opens a copy with all values filled in. Rename it and adjust it, for example to send the same submission to a different list or with different conditional logic. See [Manage Integration Feeds](/manage-integration-feeds) for the full steps.
