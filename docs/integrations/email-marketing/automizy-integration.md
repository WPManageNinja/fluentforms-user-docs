# Automizy Integration

**Automizy** is an email marketing service that lets you collect, automate, and reach visitors to your site with email templates and campaign tools. **Fluent Forms** connects your forms to any Automizy email list. This guide shows you how to connect your **Automizy** account to **[Fluent Forms Pro](/upgrade-to-pro-add-on)** and add an Automizy feed to a form.

## Enable Automizy Integration

Go to **Integrations** in the **Fluent Forms Navbar** and turn on the **Automizy** module.

![Integrations E2 B9 Test E2 Wordpress](/images/integrations/email-marketing/automizy-integration/Integrations-_E2_80_B9-Fluent-Forms-Test-_E2_80_94-WordPress-2.png)

Once you enable **Automizy**, Fluent Forms asks for the **Automizy API Token**.

![Integrations E2 B9 Test E2 Wordpress](/images/integrations/email-marketing/automizy-integration/Integrations-_E2_80_B9-Fluent-Forms-Test-_E2_80_94-WordPress-1-1.png)

### Get Your Automizy API Token

1. Log in to your [Automizy account](https://app.automizy.com/signin).
2. Go to **Settings** and click **API Token**.
3. Copy the **New API Token** that Automizy generates.

![Automizy API Fluent Forms](/images/integrations/email-marketing/automizy-integration/Automizy-api.png)

## Connect Automizy with Fluent Forms

1. Return to the **Automizy API Settings** page. To open it, go to **Integrations** in the top bar and click **Manage** next to the module.
2. Paste the **API Token** you copied from Automizy into the **Automizy API Token** field.
3. Click **Save**.

![Auto Fluent Forms](/images/integrations/email-marketing/automizy-integration/auto.png)

## Integrate Automizy Feed in Forms

1. Go to **Forms** in the **Fluent Forms Navbar**.
2. Select the form you want to connect to **Automizy** and open the **Configuration** tab.
3. Go to **Configuration** → **Integrations & Add-ons** → **Integrations**.
4. Click **Add New Integration** and select the **Automizy Integration** feed from the drawer.

![Integrations Fluent Forms](/images/integrations/email-marketing/automizy-integration/Form-Integrations-Fluent-Forms-1.png)

Then fill in the feed settings:

- **Feed Name:** Enter a name for the feed.
- **Automizy Mailing Lists:** Select the list that receives the contacts.
- **Primary Fields:** Map **Email Address**, **First Name**, and **Last Name** to your form fields.
- **Custom Fields** and **Tags:** Map extra Automizy fields and add tags if you need them.
- **Conditional Logics:** Turn on conditional logic if you need it. See [Fluent Forms Conditional Logic](/set-up-forms-with-conditional-logic).
- **Status:** Keep **Enable This feed** ticked, then click **Save**.

![Automizy Feed Fluent Forms](/images/integrations/email-marketing/automizy-integration/Automizy-feed.png)
