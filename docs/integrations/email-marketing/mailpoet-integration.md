# Mailpoet Integration

**MailPoet** is an email plugin for **WordPress** **sites** that helps you design emails and grow subscribers. With the **MailPoet** integration, Fluent Forms adds a subscriber whenever a **form** is submitted. This guide shows you how to connect [MailPoet](https://www.mailpoet.com/) to Fluent Forms.

## MailPoet with Fluent Forms

> [!Note]
> Install and activate **MailPoet** and the **Fluent Forms Connector for MailPoet** add-on before you connect the integration.

### Install and Activate the Fluent Forms Connector Add-on

1. In the **WordPress Left Sidebar**, go to **Plugins** and click **Add New Plugin**.
2. Search for **Fluent Forms Connector for MailPoet** and click **Install Now**.

![Install Connector For MailPoet](/images/integrations/email-marketing/mailpoet-integration/1.-Install-Fluent-Forms-Connector-for-MailPoet-scaled.webp)

3. Click **Activate**.

![Activate Connector For MailPoet](/images/integrations/email-marketing/mailpoet-integration/2.-Activate-Fluent-Forms-Connector-for-MailPoet-scaled.webp)

### Enable MailPoet Integration

In your **Fluent Forms Dashboard**, go to **Integrations**, search for **MailPoet**, and click the **Toggle** button to enable the **MailPoet** module.

![Enable MailPoet Fluent Forms](/images/integrations/email-marketing/mailpoet-integration/3.-Enable-MailPoet-scaled.webp)

### Integrate MailPoet in Fluent Forms

Go to **Forms** in the **Fluent Forms Dashboard** and open the **Configuration** tab of the form where you want to add the feed.

> [!Note]
> If you do not have a form yet, see [Create a Form from Scratch](/create-a-form) or [Create a Form using Templates](/using-and-customizing-pre-built-quick-forms).

![Settings MailPoet Integration](/images/integrations/email-marketing/mailpoet-integration/4.-Desired-Forms-Settings-scaled.webp)

Go to **Integrations & Add-ons** → **Integrations**, click **Add New Integration**, and select **MailPoet Integration** from the drawer.

![Configure Integrations Add Integration MailPoet](/images/integrations/email-marketing/mailpoet-integration/5.-Configure-Integrations-Add-new-integration-MailPoet-scaled.webp)

- **Feed Name:** Enter a name so you can find the feed later.
- **MailPoet List:** Select the MailPoet list that receives your contacts.
- **Primary Fields:** Match each MailPoet field with a Fluent Forms field from the dropdown. You can also enter your own custom value.
- **Custom Fields:** Add or remove fields with the **Plus** or **Minus** icon.

> [!Note]
> **Custom Fields** requires **MailPoet Pro**.

- **Send Confirmation Email:** Enable this checkbox to send a confirmation email to new contacts.

> [!Note]
> **Send Confirmation Email** requires **MailPoet Pro** and a verified MailPoet account.

- **Conditional Logic:** Run the MailPoet feed only when your form submission values match the conditions you set. Enable this option if you need it. See the [Fluent Forms Conditional Logic guide](/set-up-forms-with-conditional-logic).
- **Status:** Uncheck **Enable This Feed** to save the feed as a draft. Keep it checked to make the feed active.

Click **Save** when the configuration is done.

![MailPoet Integration Feed](/images/integrations/email-marketing/mailpoet-integration/6.-MailPoet-Integration-Feed-Fluent-Forms.webp)

The MailPoet feed now appears in the list. Click the **Toggle** button to disable the feed at any time. Click the **Settings** icon to edit it, or the **Trash** icon to delete it.

![Added MailPoet Integration Feed](/images/integrations/email-marketing/mailpoet-integration/7.-Added-MailPoet-integration-feed-scaled.webp)
