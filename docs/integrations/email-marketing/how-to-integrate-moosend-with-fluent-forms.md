# How to Integrate MooSend with Fluent Forms

Integrating **MooSend** with **Fluent Forms** allows you to collect customer information and automatically add it to the MooSend Subscriber list. This article will guide you through integrating **MooSend** with **Fluent Forms** on your **WordPress Site**.

> MooSend is the Premium Feature of the Fluent Forms Plugin. So, you need the Fluent Forms Pro plugin to integrate this.

### Enable MooSend Integration

To learn how to enable MooSend integration, follow the steps with the screenshots below – 

First, go to **Integrations** from the **Fluent Forms Navbar**, search for **MooSend** through the search bar, and get the **MooSend** integration module.

Now, turn on the **Toggle** to enable the **MooSend**. Then, you will see the MooSend’s **Settings Icon** on the right side, click on it.

![Enabled Moosend Fluent Forms](/images/integrations/email-marketing/how-to-integrate-moosend-with-fluent-forms/1.-Enabled-Moosend-scaled.webp)

Once you enable MooSend, you will be asked for the **MooSend API Key** of your **MooSend Account**.

![Moosend API Settings](/images/integrations/email-marketing/how-to-integrate-moosend-with-fluent-forms/2.-MooSend-API-Settings-scaled.webp)

### Get the MooSend API Key

To learn how to get the **MooSend API Key** from **MooSend**, follow the steps with screenshots below –

First, log in to your [MooSend Account](https://app.getgist.com/users/sign_in) and go to **Settings** from the left sidebar. 
Now, go to **Settings** from the top navbar by opening the **More** dropdown.

![Settings Video Integrate MooSend](/images/integrations/email-marketing/how-to-integrate-moosend-with-fluent-forms/3.-Settings-video-scaled.webp)

Then, click the **API Key** and you will get your desired **API Key.**

Simply, copy the **API Key** by clicking the **Copy** button. Or, to generate a new API Key, click the **Generate new API Key** button.

![Copy API Key](/images/integrations/email-marketing/how-to-integrate-moosend-with-fluent-forms/4.-Copy-API-Key.webp)

## Connect MooSend with Fluent Forms

Then, return to the **MooSend API Settings** page under the **Configure Integrations** tab of the **Global Settings** section from the **Fluent Forms** **Navbar**. 

Paste the **API Key** you copied from **MooSend** into the **MooSend API Key** field.
Finally, press the **Save Setting**s button to make your **MooSend Integration** module functional.

![Paste API Key](/images/integrations/email-marketing/how-to-integrate-moosend-with-fluent-forms/5.-Paste-ApI-Key-scaled.webp)

You can see, your MooSend is connected to your **Fluent Forms** successfully.

Now, you can verify/disconnect it anytime by clicking the **Verify Connection Again/Disconnect MooSend** buttons. 

![Verify Or Disconnect Button](/images/integrations/email-marketing/how-to-integrate-moosend-with-fluent-forms/6.-Verify-or-Disconnect-button-scaled.webp)

## Integrate MooSend in Forms

To learn how to integrate MooSend into any specific Form in Fluent Forms, follow the steps with the screenshots below –

First, go to **Forms** from the **Fluent Forms Navbar**, **select** the **Desired Form** where you want to integrate your **MooSend** and click the **Settings** button. 

> [!Note]
> If you do not have any existing forms, read [Create a Form from Scratch](/docs/how-to-create-a-form-with-fluent-forms) or [Create a Form using Templates](/docs/using-and-customizing-pre-built-quick-forms-in-fluent-forms) to create a new one.

![Open Settings Integrate MooSend](/images/integrations/email-marketing/how-to-integrate-moosend-with-fluent-forms/Open-Desired-Form-Settings-1-scaled.webp)

Once you are on the **Settings & Integrations**, go to the **Configuration Integrations** tab, click the **Add New Integration** button, and select **MooSend Integration** from the dropdown list. 

![Add Integration Button Integrate MooSend](/images/integrations/email-marketing/how-to-integrate-moosend-with-fluent-forms/7.-Add-new-Integration-button-scaled.webp)

Here, you will find a required field to set a **Name** for your integration feed according to your preference.

Also, you must select the **MooSend Mailing List** from the dropdown where you want to send the submitted form data.

![Moosend Mailing List](/images/integrations/email-marketing/how-to-integrate-moosend-with-fluent-forms/8.-MooSend-Mailing-List-scaled.webp)

Once you select the integration, a page will appear with various settings options for configuring the MooSend.

**All the settings options mentioned in the screenshot below are briefly explained:**

1. Name: Here, you can see a name is given by default for your integration. You can change the name anytime if needed.

1. MooSend Mailing Lists: From here, you can change the MooSend Mailing List anytime if needed.

1. Map Fileds: Use all the fields under this option to properly link your MooSend Fields with the Form Fields. You can easily select the value for the Form Fields based on the MooSend fields using the Shortcode Arrow.

1. Double Opt-in: Enable this option if you want to check the validation of the user information (specifically user email).

1. Conditional Logics: This option allows MooSend integration to function conditionally based on your submission values according to your set conditional logic/s. To learn more, read this Documentation.

1. Enable This Feed: Check this option, to ensure this integration feed remains enabled, and all the actions of this feed function properly.

Once the setup is done, finally, click the **Save Feed** button. And, your MooSend will be integrated into this specific form!

![Save Feed Button Integrate MooSend](/images/integrations/email-marketing/how-to-integrate-moosend-with-fluent-forms/9.-Save-Feed-button-scaled-2.webp)

After successful Integration, now you will see that your **MooSend Integration Feed** has been added here. 

You can modify your feed anytime by clicking the **Settings Icon** and delete it by clicking the **Trash Icon**.
Also, you can disable or enable this feed anytime by turning off the **Toggle** if needed.

![Added Moosend Integration Feed](/images/integrations/email-marketing/how-to-integrate-moosend-with-fluent-forms/10.-Added-MooSend-Integration-Feed-scaled.webp)
