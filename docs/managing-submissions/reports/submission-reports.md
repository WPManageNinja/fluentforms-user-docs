# Submission Reports

The **Reports** **Submissions** tab gives you a detailed look at the performance and status of your form entries. Use it to track submission volume, monitor engagement through read rates, and spot trends over time. For revenue and transaction analytics, see [Payment Reports](/payment-reports).

## Accessing the Submission Reports

In your WordPress dashboard, go to **Fluent Forms** > **Reports** in the top menu bar. The **Overview** tab opens first. Select the **Submissions** tab to see the submission reports.

### Filtering Submission Data

Filters at the top of the page apply to the entire report.

- **All Forms:** View data for all forms, or select a single form to analyze.
- **Date Range:** Click the date filter to select a time period, such as Last month, or choose a custom range.

### Submissions Chart

This chart gives a quick overview of your submission activity for the selected period.

- **Total:** The total number of submissions received.
- **Read:** The count of entries that have been viewed.
- **Unread:** The count of entries that have not yet been viewed.
- **Spam:** The number of submissions flagged as spam.
- **Overall Read Rate:** The percentage of total submissions marked as read.

![Submission Fluent Forms](/images/managing-submissions/reports/submission-reports/Submission-01.webp)

### Analyzing the Submissions Chart

The **Submissions** bar chart shows entry volume and status over time. The color-coded bars match the legend on the right, which lists statuses such as **Read**, **Unread**, **Spam**, and **Trashed**. Use it to see which days had the most activity and the status of those entries.

![Submission Charts](/images/managing-submissions/reports/submission-reports/submission-cahrts-02.webp)

### Using the Submission Analysis Table (Pro)

This table breaks down your submission data in more detail. By default, it analyzes data by **Forms**, with columns for **Total Submissions**, **Read**, **Unread**, **Spam**, and **Read Rate** for each form.

Use the dropdown menu at the top right of the table to change the analysis type. You can group the data by:

- Forms
- Submission Source
- Email
- Country
- Submission Date

![Submission Analysis By](/images/managing-submissions/reports/submission-reports/submission-analysis-by-forms-03-scaled.webp)
