# Getting Started With Fluent Forms

Welcome to [Fluent Forms](https://wordpress.org/plugins/fluentform/) documentation.

Fluent Forms is a powerful, user-oriented WordPress plugin that allows you to create amazing forms without requiring any coding skills.

With its simple drag-and-drop interface, you can quickly create forms that look and function exactly as you want. Whether you need a simple contact form or a complex multi-step form, **Fluent Forms** has you covered.

### Key Features

- Drag and drop form builder

- Advanced field option

- Conditional logic

- Integration with popular CRM tools

- Advanced Customization options

Let's see how you can Install, Upgrade, and use this all-in-one form builder plugin for WordPress.

This segment of Fluent Forms documentation contains a user manual on the initial operations of this plugin.
