# Form Fields

Fields are the building blocks of every form — and **Fluent Forms** gives you a rich library of them so you can collect exactly the data you need, the way you need it. From simple text inputs to advanced grids, smart containers, and post-publishing fields, there's a field for every job. This page introduces each group of fields and links you straight to the guide for the one you want.

## General Fields

The everyday essentials. These cover the most common inputs you'll reach for on contact forms, sign-ups, and surveys.

- [Simple Text](/adding-a-simple-text-input-field) — single-line text for names, subjects, and short answers.
- [Text Area](/adding-a-text-area-input-field) — multi-line input for messages and comments.
- [Name](/name-input-field) — structured first/middle/last name capture.
- [Email Address](/email-address-input-field) — validated email collection.
- [Numeric](/numeric-input-field) — numbers only, with optional limits.
- [Phone / Mobile](/phonemobile-input-field) — phone numbers with country formatting.
- [Address](/address-input-field) — full address with street, city, and country.
- [Website URL](/website-url-input-field-guide) — validated web addresses.
- [Mask Input](/adding-a-mask-input-field-guide) — enforce a custom input pattern.
- [Dropdown](/dropdown-field) — single choice from a list.
- [Radio](/radio-field) — pick one visible option.
- [Checkbox](/checkbox-field) — select one or more options.
- [Multiple Choice](/multiple-choice-field) — styled single or multi-select choices.
- [Country List](/country-list-field) — ready-made country selector.
- [Time & Date](/time-date-input-field) — date and time picker.
- [File Upload](/file-upload-input-field) — let users attach files.
- [Image Upload](/image-upload-input-field) — collect image uploads.
- [Custom HTML](/custom-html-field) — add your own markup inside a form.

## Advanced Fields

Powerful inputs for richer forms — quizzes, bookings, agreements, dynamic data, and more.

- [Action Hook](/action-hook-field) — insert custom content via a hook.
- [Chained Select](/chained-select-field) — linked dropdowns that filter each other.
- [Checkable Grid](/checkable-grid-input-field) — matrix of checkable options.
- [Color Picker](/color-picker-field) — let users choose a color.
- [Custom Submit Button](/custom-submit-button) — style and customize the submit button.
- [Dynamic Field](/dynamic-field) — pull options from posts, users, or taxonomies.
- [FluentBooking](/fluentbooking-field) — embed a booking selector in your form.
- [GDPR Agreement](/gdpr-agreement-field) — add a GDPR consent checkbox.
- [Hidden](/hidden-input-field) — store values invisibly.
- [Net Promoter Score (NPS)](/net-promoter-score) — measure customer loyalty.
- [Password](/password-input-field) — secure password input.
- [Quiz Score](/quiz-score) — calculate and show quiz results.
- [Range Slider](/range-slider-field) — select a value on a slider.
- [Ratings](/ratings-input-field) — collect star ratings.
- [Repeat Field](/repeat-input-field) — let users add repeating rows.
- [Rich Text](/rich-text-input-field) — formatted text input.
- [Save Progress Button](/save-progress-button) — let users save and resume later.
- [Section Break](/section-break) — divide a form into clear sections.
- [Shortcode](/shortcode-input-field) — render a shortcode inside the form.
- [Terms & Conditions](/terms-conditions-field) — require agreement before submitting.

## Container Fields

Control your layout. Containers let you group fields side by side and build clean, organized forms.

- [Container](/add-container-fields) — place fields in multi-column rows.
- [Accordion Container](/add-accordion-container-fields) — collapsible sections to save space.
- [Repeat Container](/add-repeat-container-field) — repeat a whole group of fields.
- [Resizeable Container](/resizeable-container) — adjust column widths freely.

- [Post Title](/add-post-title-field-in-post-forms) — capture the post title.
- [Post Content](/add-post-content-field-in-post-forms) — collect the main post body.
- [Post Excerpt](/add-post-excerpt-field-in-post-forms) — add a short summary.
- [Featured Image](/add-featured-image-field-in-post-forms) — set the post's featured image.
- [Post Update](/add-post-update-field-in-post-forms) — let users edit existing posts.
- [Categories](/add-categories-taxonomy-field-in-post-forms) — assign post categories.
- [Tags](/add-tags-taxonomy-field-in-post-forms) — assign post tags.
