# Form Fields in Fluent Forms

Fields are the building blocks of every form — and **Fluent Forms** gives you a rich library of them so you can collect exactly the data you need, the way you need it. From simple text inputs to advanced grids, smart containers, and post-publishing fields, there's a field for every job. This page introduces each group of fields and links you straight to the guide for the one you want.

## General Fields

The everyday essentials. These cover the most common inputs you'll reach for on contact forms, sign-ups, and surveys.

- [Simple Text](/docs/adding-a-simple-text-input-field) — single-line text for names, subjects, and short answers.
- [Text Area](/docs/adding-a-text-area-input-field) — multi-line input for messages and comments.
- [Name](/docs/name-input-field-in-fluent-forms) — structured first/middle/last name capture.
- [Email Address](/docs/email-address-input-field-in-fluent-forms) — validated email collection.
- [Numeric](/docs/numeric-input-field-in-fluent-forms) — numbers only, with optional limits.
- [Phone / Mobile](/docs/phonemobile-input-field-in-fluent-forms) — phone numbers with country formatting.
- [Address](/docs/address-input-field-in-fluent-forms) — full address with street, city, and country.
- [Website URL](/docs/website-url-input-field-guide) — validated web addresses.
- [Mask Input](/docs/adding-a-mask-input-field-guide) — enforce a custom input pattern.
- [Dropdown](/docs/dropdown-field-in-fluent-forms) — single choice from a list.
- [Radio](/docs/radio-field-in-fluent-forms) — pick one visible option.
- [Checkbox](/docs/checkbox-field-in-fluent-forms) — select one or more options.
- [Multiple Choice](/docs/multiple-choice-field-in-fluent-forms) — styled single or multi-select choices.
- [Country List](/docs/country-list-field-in-fluent-form) — ready-made country selector.
- [Time & Date](/docs/time-date-input-field-in-fluent-forms) — date and time picker.
- [File Upload](/docs/file-upload-input-field-in-fluent-forms) — let users attach files.
- [Image Upload](/docs/image-upload-input-field-in-fluent-form) — collect image uploads.
- [Custom HTML](/docs/custom-html-field-in-fluent-forms) — add your own markup inside a form.

## Container Fields

Control your layout. Containers let you group fields side by side and build clean, organized forms.

- [Container](/docs/add-container-fields-in-fluent-forms) — place fields in multi-column rows.
- [Accordion Container](/docs/add-accordion-container-fields-in-fluent-forms) — collapsible sections to save space.
- [Repeat Container](/docs/add-repeat-container-field-in-fluent-forms) — repeat a whole group of fields.
- [Resizeable Container](/docs/resizeable-container-in-fluent-forms) — adjust column widths freely.
