# Radio Field

The **Radio Field** in **Fluent Forms** lets users select a **single option** from a predefined list. Use it for **multiple-choice questions, surveys, and single-option selections**.

This article shows you how to add the **Radio Field** to your form.

## Adding Radio Field

Go to **Forms** in the Fluent Forms navbar. Click the title of the form you want to edit to open the form editor.

![Editor Fluent Forms](/images/form-fields/general-fields/radio-field/Editor-Form-01-scaled.webp)

In the editor, click the **Plus Icon** and open the **General Fields** module. You can also find **General Fields** in the right sidebar under the **Input Fields** tab.

Click the **Radio Field**, or drag and drop it into your editor.

![Radio Field step](/images/form-fields/general-fields/radio-field/new-10-scaled.webp)

## Customizing the Radio Field

Hover over the field and click the **Pencil Icon**. The **Customize** tab opens on the right side with these options:

- Radio Field Options

- Advanced Options

![Customize](/images/form-fields/general-fields/radio-field/Input-customization-03-8-scaled.webp)

### Radio Field Options

These options in the **Customize** tab configure the **Radio Field.**

**A. Element Label:** The field title users see when they fill out the **Radio** field. Enter text that explains the purpose of the field.

**B. Label Placement:** Set where the label appears. The options are **Default**, **Top**, **Right**, **Bottom**, **Left**, and **Hide Label**. **Default** uses your global label placement settings.

**C. Admin Field Label:** The admin field label is a title shown only to admins. Use it to show a different label when admins view form submissions.

**D. Options:** Define the radio options:

- **Create Options:** Add the items for users to choose from.

- **Set Default Options:** Checkmark an option to set it as the default selection.

- **Show Values:** Display values for admin ease during submissions.

- **Rearrange Options:** Drag and drop options to reorder them.

- **Add/Delete Options:** Use the **Plus Icon** to add new options or insert options between existing ones.

**E. Show & Calc Value:** Use **Show Values** to display your data and **Calc Values** to perform [numeric calculations](/numeric-calculation).

Click the **Photo** option to add photos to the field.

**F. Bulk Edit/Predefined Data Sets:** Choose a predefined data set for the radio options, or import one, instead of adding each option manually. This suits lists like countries or states.

**G. Shuffle the available options:** Turn this on to show the radio options in a random order to each user.

**H. Layout:** Choose a layout for the options. Available layouts are **Default**, **Inline Layout**, **Button Type Styles**, **2-Column Layout**, **3-Column Layout**, **4-Column Layout**, and **5-Column Layout**.

**I. Enable "Other" Option:** Turn this on to let users pick **Other** and type their own answer. You can then set an **Other Option Label**, an **Other Option Placeholder**, and an **Other Option Required Message**. The message shows when a user selects **Other** and leaves the text box empty.

**J. Required:** Turn on **Required** to make users select an option before they submit.

![Basic Options](/images/form-fields/general-fields/radio-field/Basic-options-04-8-scaled.webp)

### Advanced Options

Advanced settings let you adapt the field to specific use cases.

**A. Dynamic Default Value:** Set a fixed value, or use shortcodes to pre-fill the field dynamically. To learn more, read [Dynamic Default Value in Fluent Forms](/dynamic-default-value).

**B. Container Class:** Add custom CSS classes to the field’s wrapper.

**C. Help Message:** Add text that appears as a help message for the user.

**D. Name Attribute:** The input field’s name attribute is the HTML equivalent of the same name. You do not need to change it.

**E. Conditional Logic:** Create rules that show or hide the field based on submission values. To learn more, read [Set up Forms with Conditional Logic in Fluent Forms](/set-up-forms-with-conditional-logic). 

![Advanced Option X439](/images/form-fields/general-fields/radio-field/Advanced-option-05-1-1024x439.webp)

## Embedding the Form on Your Website

Click **Save** to keep your changes. Click the **Preview** (eye) icon at the top right to see the form preview.

To show the form on a page or post, copy the **Shortcode** from the top right and paste it into that page or post.

![Save Radio Field](/images/form-fields/general-fields/radio-field/Save-Form-06-9-scaled.webp)

### Image Button Layout

1. Enable the **Photo** option in the radio field’s options.
2. Upload an image for each option in the **Photo** setting.

![Photo](/images/form-fields/general-fields/radio-field/Photo-08-1-scaled.webp)

3. In the field options, select **Button Type Styles** from the **Layout** dropdown.

![Button Layout Radio Field](/images/form-fields/general-fields/radio-field/button-layout-09-scaled.webp)

The radio field now shows clickable image options.

![Button Style Preview Radio Field](/images/form-fields/general-fields/radio-field/button-style-preview-10.webp)
