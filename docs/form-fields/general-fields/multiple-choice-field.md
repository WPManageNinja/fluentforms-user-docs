# Multiple Choice Field

The **Multiple Choice Field** in [Fluent Forms](https://wordpress.org/plugins/fluentform/) lets users select one or multiple answers from a predefined list of options. Use it for surveys, quizzes, product selection, and other cases where multiple answers may be valid.

This article shows you how to add the **multiple-choice** field to your form.

## Adding Multiple Choice Field

Go to **Forms** in the Fluent Forms navbar. Click the title of the form you want to edit to open the form editor.

![Edit Multiple Choice Field](/images/form-fields/general-fields/multiple-choice-field/edit-form-01-4-scaled.webp)

In the editor, click the **Plus Icon** and open the **General Fields** module. You can also find **General Fields** in the right sidebar under the **Input Fields** tab.

Click the **Multiple Choice** field, or drag and drop it into your editor.

![Multiple Choice Field step](/images/form-fields/general-fields/multiple-choice-field/new-8-scaled.webp)

## Customizing the Multiple Choice Field

Hover over the field and click the **Pencil Icon**. The **Customize** tab opens on the right side with these options:

- Multiple Choice Options

- Advanced Options

![Customize](/images/form-fields/general-fields/multiple-choice-field/input-customization-03-6-scaled.webp)

### Multiple Choice Options

These options in the **Customize** tab configure the **Multiple Choice** field.

**A. Element Label:** The field title users see when they fill out the **Multiple Choice** field. Enter text that explains the purpose of the field.

**B. Label Placement:** Set where the label appears. The options are **Default**, **Top**, **Right**, **Bottom**, **Left**, and **Hide Label**. **Default** uses your global label placement settings.

**C. Admin Field Label:** The admin field label is a title shown only to admins. Use it to show a different label when admins view form submissions.

**D. Placeholder:** Set the text shown while the field is empty, so users know what to enter. This is the HTML input placeholder attribute.

**E. Options:** Create multiple choices for users to select from.

- **Enable Option Grouping:** Turn this on to organize your choices into labeled sections. Click **Create New Option Group** to add a group, then add options inside it.

![Enable Option Grouping](/images/form-fields/general-fields/multiple-choice-field/enable-option-grouping.webp)

- **Add, Remove, or Edit Options.**

- **Insert an Option Anywhere** using the Plus Icon.

- **Drag & Drop to Rearrange Options.**

**F. Show Values / Calc Values:** Turn on **Show Values** to display each option's value for admin reference, or **Calc Values** to assign numeric values so you can perform [numeric calculations](/numeric-calculation).

![Basic Options](/images/form-fields/general-fields/multiple-choice-field/Basic-options-04-6-scaled.webp)

**G. Bulk Edit/Predefined Data Sets:** Choose a predefined data set for the field, or import one, instead of adding each option manually. This suits lists like countries or states.

![Bulk Edit Predefined Data Sets](/images/form-fields/general-fields/multiple-choice-field/bulk-edit-predefined-data-sets.webp)

**H. Shuffle the available options:** Turn this on so every user sees the options in a random order.

**I. Required:** Turn on **Required** to make users select an option before they submit.

**J. Max Selection:** Set the maximum number of options a user can select. Leave it blank for no limit.

**K. Min Selection:** Set the minimum number of options a user must select before submitting the form. Leave it blank for no minimum.

![Max and Min Selection](/images/form-fields/general-fields/multiple-choice-field/max-and-minimum.webp)

### Advanced Options

Advanced settings let you adapt the field to specific use cases.

**A. Autocomplete:** Choose a value that tells the browser what the field collects, so it can offer saved details. To learn more, read [Autocomplete for Form Fields](/autocomplete-for-form-fields).

**B. Dynamic Default Value:** Set a fixed value, or use shortcodes to pre-fill the field dynamically. To learn more, read [Dynamic Default Value in Fluent Forms](/dynamic-default-value).

**C. Container Class:** Add custom CSS classes to the field’s wrapper.

**D. Element Class:** Add custom CSS classes to the input field.

**E. Help Message:** Add text that appears as a help message for the user.

**F. Name Attribute:** The input field’s name attribute is the HTML equivalent of the same name. You do not need to change it.

**G. Conditional Logic:** Create rules that show or hide the field based on submission values. To learn more, read [Set up Forms with Conditional Logic in Fluent Forms](/set-up-forms-with-conditional-logic). 

![Advance Doptions](/images/form-fields/general-fields/multiple-choice-field/Advance-doptions-05-scaled.webp)

## Embedding the Form into Frontend

Click **Save** to keep your changes. Click the **Preview** (eye) icon at the top right to see the form preview.

To show the form on a page or post, copy the **Shortcode** from the top right and paste it into that page or post.

![Save Multiple Choice Field](/images/form-fields/general-fields/multiple-choice-field/save-form-06-7-scaled.webp)
