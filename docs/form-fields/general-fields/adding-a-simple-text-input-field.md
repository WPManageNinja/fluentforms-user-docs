# Adding a Simple Text Input Field

The **Simple Text Input Field** in **Fluent Forms** collects **single-line text responses**, such as names, addresses, or short answers. This article shows you how to add the **Simple Text** field to your form.

## Adding Simple Text Input Field

Go to **Forms** in the Fluent Forms navbar. Click the title of the form you want to edit to open the form editor.

![Edit a Simple Text Input](/images/form-fields/general-fields/adding-a-simple-text-input-field/edit-form-01-5-scaled-2.webp)

In the editor, click the **Plus Icon** and open the **General Fields** module. You can also find **General Fields** in the right sidebar under the **Input Fields** tab.

Click the **Simple Text** field, or drag and drop it into your editor.

![a Simple Text Input Field step](/images/form-fields/general-fields/adding-a-simple-text-input-field/new-12-scaled.webp)

## Customizing the Simple Text Field

Hover over the field and click the **Pencil Icon**. The **Customize** tab opens on the right side with these options:

- Simple Text Options

- Advanced Options

![Customize Fluent Forms](/images/form-fields/general-fields/adding-a-simple-text-input-field/Input-Customization-03-10-scaled.webp)

### Simple Text Options

These options in the **Customize** tab configure the **Simple Text** field.

**A. Element Label:** The field title users see when they fill out the **Simple Text** field. Enter text that explains the purpose of the field.

**B. Label Placement:** Set where the label appears. The options are **Default**, **Top**, **Right**, **Bottom**, **Left**, and **Hide Label**. **Default** uses your global label placement settings.

**C. Admin Field Label:** The admin field label is a title shown only to admins. Use it to show a different label when admins view form submissions.

**D. Placeholder:** Set the text shown while the field is empty, so users know what to enter. This is the HTML input placeholder attribute.

**E. Required:** Turn on **Required** to stop users from submitting the form with this field empty.

![Basic Options Fluent Forms](/images/form-fields/general-fields/adding-a-simple-text-input-field/Basic-Options-04-10-scaled.webp)

### Advanced Options

Advanced settings let you adapt the field to specific use cases.

**A. Autocomplete:** Choose a value that tells the browser what the field collects, so it can offer saved details. Options are **Automatic**, **off**, **None**, or a specific value. To learn more, read [Autocomplete for Form Fields](/autocomplete-for-form-fields).

**B. Default Value:** Set a fixed value, or use shortcodes to pre-fill the field dynamically. To learn more, read [Dynamic Default Value](/dynamic-default-value).

**C. Container Class:** Add custom CSS classes to the field’s wrapper.

**D. Element Class:** Add custom CSS classes to the input field.

**E. Help Message:** Add text that appears as a help message for the user.

**F. Prefix Label:** Add text that shows in the input field as a prefix.

**G. Suffix Label:** Add text that shows in the input field as a suffix.

**H. Name Attribute:** The input field’s name attribute is the HTML equivalent of the same name. You do not need to change it.

**I. Max text length:** Set the maximum number of characters the field accepts. Use it to limit responses like postal codes or short codes.

**J. Validate as Unique:** Require the input value to be unique among all submissions. If it is not unique, users see an error message. Learn more in [Unique Field Validation](/unique-field-validation).

**K. Conditional Logic:** Create rules that show or hide the field based on submission values. To learn more, read [Set up Forms with Conditional Logic in Fluent Forms](/set-up-forms-with-conditional-logic).

![Advanced Options](/images/form-fields/general-fields/adding-a-simple-text-input-field/Advanced-options-05-8-scaled.webp)

## Embedding the Form on Your Website

Click **Save** to keep your changes. Click the **Preview** (eye) icon at the top right to see the form preview.

To show the form on a page or post, copy the **Shortcode** from the top right and paste it into that page or post.

![Save Fluent Forms](/images/form-fields/general-fields/adding-a-simple-text-input-field/Save-Form-06-11-scaled.webp)
