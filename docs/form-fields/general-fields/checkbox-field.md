# CheckBox Field

The **CheckBox Field** in Fluent Forms lets users select one or more options from a list. Use it for surveys, polls, preferences, or consent forms.

This article shows you how to add the **Checkbox** field to your form.

## Adding the Checkbox Field

Go to **Forms** in the Fluent Forms navbar. Click the title of your form to open the editor.

![Editor Fluent Forms](/images/form-fields/general-fields/checkbox-field/form-editor-01-scaled.webp)

In the editor, click the **Plus Icon** and open the **General Fields** module. You can also find **General Fields** in the right sidebar under the **Input Fields** tab.

Click the **Checkbox** field, or drag and drop it into your editor.

![CheckBox Field step](/images/form-fields/general-fields/checkbox-field/new-1-scaled.webp)

## Customizing the Checkbox Field

Hover over the field and click the **Pencil Icon**. The **Customize** tab opens on the right side with these options:

- Checkbox Field Options

- Advanced Options

![Edit Checkbox Field](/images/form-fields/general-fields/checkbox-field/Edit-checkbox-field-03-scaled.webp)

### Checkbox Field Options

These options in the **Customize** tab configure the **Checkbox** field.

**A. Element Label:** The field title users see when they fill out the **Checkbox** field. Enter text that explains the purpose of the field.

**B. Label Placement:** Set where the label appears. The options are **Default**, **Top**, **Right**, **Bottom**, **Left**, and **Hide Label**. **Default** uses your global label placement settings.

**C. Admin Field Label:** The admin field label is a title shown only to admins. Use it to show a different label when admins view form submissions.

**D. Options:** Define the options users can choose from:

- **Show Values:** Display values for admin ease during submissions.

- **Calc Values:** Assign numeric values to options so you can perform [numeric calculations](/numeric-calculation).

- **Photo:** Use an image for each option instead of plain text.

- **Create Options:** Add the items for users to choose from.

- **Set Default Options:** Checkmark an option to set it as the default selection.

- **Rearrange Options:** Drag and drop options to reorder them.

- **Add/Delete Options:** Use the **Plus Icon** to add new options or insert options between existing ones.

- **Bulk Edit/Predefined Data Sets:** Choose a predefined data set, or import one, instead of adding each option manually. This suits lists like countries or states.

![Bulk Fluent Forms](/images/form-fields/general-fields/checkbox-field/bulk-scaled.webp)

**E. Layout:** Choose a layout for the options. Available layouts are **Default**, **Inline Layout**, **Button Type Styles**, **2-Column Layout**, **3-Column Layout**, **4-Column Layout**, and **5-Column Layout**.

**F. Shuffle the available options:** Turn this on to show the checkbox options in a random order to each user.

**G. Required:** Turn on **Required** to make users select at least one option before they submit.

**H. Max Selection:** Set the maximum number of options a user can select. Leave it blank for no limit.

**I. Min Selection:** Set the minimum number of options a user must select before submitting the form. Leave it blank for no minimum.

![Basic Options](/images/form-fields/general-fields/checkbox-field/Basic-options-04-scaled.webp)

**J. Enable "Other" Option:** Turn this on to add an editable **Other** choice at the end of the list, letting users type in an answer that isn't part of your predefined options.

- **Other Option Label:** The label shown for the extra choice. Defaults to "Other."

- **Other Option Placeholder:** The placeholder text shown inside the **Other** text input.

- **Other Option Required Message:** The validation message shown if a user selects **Other** but leaves the text input empty.

![Basic Options](/images/form-fields/general-fields/checkbox-field/enable-other-option.webp)

### Advanced Options

Advanced settings let you adapt the field to specific use cases.

**A. Dynamic Default Value:** Set a fixed value, or use shortcodes to pre-fill the field dynamically. To learn more, read [Dynamic Default Value in Fluent Forms](/dynamic-default-value).

**B. Container Class:** Add custom CSS classes to the field’s wrapper.

**C. Help Message:** Add text that appears as a help message for the user.

**D. Name Attribute:** The input field’s name attribute is the HTML equivalent of the same name. You do not need to change it.

**E. Conditional Logic:** Create rules that show or hide the field based on submission values. To learn more, read [Set up Forms with Conditional Logic in Fluent Forms](/set-up-forms-with-conditional-logic). 

![Advanced Options](/images/form-fields/general-fields/checkbox-field/advanced-options-05-1-scaled.webp)

## Embed the Form into the Front

Click **Save** to keep your changes. Click the **Preview** (eye) icon at the top right to see the form preview.

To show the form on a page or post, copy the **Shortcode** from the top right and paste it into that page or post.

![Save CheckBox Field](/images/form-fields/general-fields/checkbox-field/save-form-06-1-scaled.webp)

### Image Button Layout

1. Enable the **Photo** option in the checkbox field’s options, as shown in the screenshot.
2. Upload an image for each option in the **Photo** setting.

![Photo Fluent Forms](/images/form-fields/general-fields/checkbox-field/photo-08-scaled.webp)

3. Under **Checkbox Field Options**, select the **Button Layout** you want from the **Layout** dropdown.

![Button Layout Style CheckBox Field](/images/form-fields/general-fields/checkbox-field/button-layout-style-09-scaled.webp)

The checkbox field now shows clickable image options.
