# FluentBooking Field

[FluentBooking](https://fluentbooking.com/) is a plugin for managing appointments, meetings, webinars, events, and sales calls. With **Fluent Forms**, users can schedule a booking and enter the booking details in your form.

This guide shows you how to add and customize the **FluentBooking Field** in Fluent Forms.

> [!Note]
> Install and activate the [FluentBooking](https://fluentbooking.com/) plugin first. The **FluentBooking** field then appears under **Advanced Fields** in the form editor.

## Adding FluentBooking Field

Go to **Forms** in the Fluent Forms navbar. Click the title of the form you want to edit to open the form editor.

> [!Note]
> If you have no forms yet, read [Create a Form from Scratch](/create-a-form) or [Create a Form using Templates](/using-and-customizing-pre-built-quick-forms).

![Edit FluentBooking Field in Fluent](/images/form-fields/advanced-fields/fluentbooking-field/Form-edit-01-4-scaled.webp)

In the editor, click the **Plus Icon** and open the **Advanced Fields** section.

Click the **FluentBooking Field**, or drag and drop it into your editor.

![Adding Booking](/images/form-fields/advanced-fields/fluentbooking-field/adding-Fluent-Booking-02-scaled.webp)

## Customizing the FluentBooking Field

After you add the FluentBooking field, hover over it and click the **Pencil Icon**. The **Customize** tab opens on the right side with these options:

- FluentBooking Field

- Advanced Options

![Customize Fluent Forms](/images/form-fields/advanced-fields/fluentbooking-field/Input-Customization-03-33-scaled.webp)

### FluentBooking Field Option

These options in the **Customize** tab configure the **FluentBooking** input field.

**A. Element Label:** The field title users see when they fill out the FluentBooking field. Enter text that explains the field's purpose.

**B. Admin Field Label:** The admin field label is a title shown only to admins. Use it to show a different label when admins view form submissions.

**C. Select Calendar:** Choose a calendar from the dropdown. The calendar must be created using the **FluentBooking** plugin.

**D. Select Guest Email Field:** Map the email field so Fluent Forms collects the guest email.

**E. Select Guest Name Field:** Map the **Name** field to identify the user.

**F. Show Host Info:** Check **Show Host Info** to show your host details.

**G. Required:** Choose whether users can submit the form with this field empty.

![Booking Options](/images/form-fields/advanced-fields/fluentbooking-field/Fluent-booking-options-04-scaled.webp)

### Advanced Options

Advanced settings let you adapt the field to specific use cases.

**A. Container Class:** Add custom CSS classes to the field’s wrapper.

**B. Name Attribute:** The input field’s name attribute is the HTML equivalent of the same name. You do not need to change it.

**C. Conditional Logic:** Create rules that show or hide the field based on submission values. To learn more, read the [Conditional Logic documentation](/set-up-forms-with-conditional-logic). 

![Advanced Options Fluent Forms](/images/form-fields/advanced-fields/fluentbooking-field/Advanced-options-05-22-scaled.webp)

## Embed the Form into the Frontend

Click **Save** to apply your changes.

To show the form on a page or post, copy the **Shortcode** from the top-right corner and paste it into that page or post.

To preview the form, click the **Preview** (eye) icon at the top right.
