# Hidden Input Field

The **hidden** input field in Fluent Forms lets you store and retrieve data **without displaying it** on the form. Use it to track user data, pass [dynamic values from URL parameters](/set-default-form-value-from-url-parameters), or store information for backend processing.

This article shows you how to add the **Hidden** field to your form.

## Adding the Hidden Field

Go to **Forms** in the Fluent Forms navbar. Click the title of the form you want to edit to open the form editor.

> [!Note]
> If you have no forms yet, read [Create a Form from Scratch](/create-a-form) or [Create a Form using Templates](/using-and-customizing-pre-built-quick-forms).

![Edit Hidden Input Field](/images/form-fields/advanced-fields/hidden-input-field/edit-form-01.png)

In the editor, click the **Plus Icon** and open the **Advanced Fields** module. You can also find **Advanced Fields** in the right sidebar under the **Input Fields** tab.

Click the **Hidden** field, or drag and drop it into your editor.

![Hidden Input Field step](/images/form-fields/advanced-fields/hidden-input-field/new.png)

## Customizing the Hidden Field

Hover over the field and click the **Pencil Icon**. The **Customize** tab opens on the right side.

![Customize](/images/form-fields/advanced-fields/hidden-input-field/input-customization-03.png)

These options in the **Customize** tab configure the **hidden** field.

**A. Admin Field Label:** The admin field label is a title shown only to admins. Use it to show a different label when admins view form submissions.

**B. Default Value:** Set a fixed value, or use shortcodes to pre-fill the field dynamically. To learn more, read the [Dynamic Default Value documentation](/dynamic-default-value). You can add different default values by clicking the **Three-dot** options from the right side.

**C. Name Attribute:** The input field’s name attribute is the HTML equivalent of the same name. You do not need to change it.

![Customization Fluent Forms](/images/form-fields/advanced-fields/hidden-input-field/customization-04.png)

## Embed the Form into Frontend

Click **Save** to keep your changes. Click the **Preview** (eye) icon at the top right to see the form preview.

To show the form on a page or post, copy the **Shortcode** from the top right and paste it into that page or post.

![Save Hidden Input Field](/images/form-fields/advanced-fields/hidden-input-field/save-form-05.png)
