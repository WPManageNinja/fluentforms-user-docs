# Color Picker Field

The **Color Picker** field in Fluent Forms lets users select a color in **hexadecimal color format (#RRGGBB)**. Use it for customization, branding, or product selection.

This guide shows you how to add and customize the **Color Picker** field in Fluent Forms.

> [!Note]
> The **Color Picker** field requires **Fluent Forms Pro**. See [Upgrade to Fluent Forms Pro Add-on](/upgrade-to-pro-add-on).

## Adding a Color Picker Field

Go to **Forms** in the Fluent Forms navbar. Click the title of the form you want to edit to open the form editor.

> [!Note]
> If you have no forms yet, read [Create a Form from Scratch](/create-a-form) or [Create a Form using Templates](/using-and-customizing-pre-built-quick-forms).

![Editor](/images/form-fields/advanced-fields/color-picker-field/form-editor-01-4-scaled.webp)

In the editor, click the **Plus Icon** and open the **Advanced Fields** module. You can also find **Advanced Fields** in the right sidebar under the **Input Fields** tab.

Click the **Color Picker** field, or drag and drop it into your editor.

![Adding Color Picker Field](/images/form-fields/advanced-fields/color-picker-field/adding-color-picker-field-02-scaled.webp)

## Customizing the Color Picker Field

After you add the **Color Picker** field, hover over it and click the **Pencil Icon**. The **Customize** tab opens on the right with these options:

- Color Picker Field Options

- Advanced Options

![Customize Fluent Forms](/images/form-fields/advanced-fields/color-picker-field/Input-Customization-03-27-scaled.webp)

### Color Picker Field Options

These options in the **Customize** tab configure the **Color Picker** field.

**A. Element Label:** The field title users see when they fill out the **Color Picker** field. Enter text that explains the purpose of the field.

**B. Admin Field Label:** The admin field label is a title shown only to admins. Use it to show a different label when admins view form submissions.

**C. Placeholder:** Set the text shown while the field is empty, so users know what to enter. This is the HTML input placeholder attribute.

**D. Default Value:** Set a fixed value, or use shortcodes to pre-fill the field dynamically. To learn more, read the [Dynamic Default Value documentation](/dynamic-default-value). 

Click the **Three-Dot** option on the right to add a default value.

**E. Label Placement:** Set where the label appears. The options are **Default**, **Top**, **Right**, **Bottom**, **Left**, and **Hide Label**. **Default** uses your **Global** label placement settings.

**F. Required:** Turn on **Required** to make users fill in this field before they submit.

![Unnamed Fluent Forms](/images/form-fields/advanced-fields/color-picker-field/unnamed.webp)

### Advanced Options

Advanced settings let you adapt the field to specific use cases.

**A. Name Attribute:** The input field’s name attribute is the HTML equivalent of the same name. You do not need to change it.

**B. Help Message:** Add text that appears as a help message for the user.

**C. Container Class:** Add custom CSS classes to the field’s wrapper.

**D. Element Class:** Add custom CSS classes to the input field.

**E. Conditional Logic:** Create rules that show or hide the field based on submission values. To learn more, read [Conditional Logic documentation](/set-up-forms-with-conditional-logic).

![Advanced Options](/images/form-fields/advanced-fields/color-picker-field/Advanced-Options-04-2-scaled.webp)

### Embed the Form into Frontend

Click **Save** to keep your changes. Click the **Preview** (eye) icon at the top right to see the form preview.

To show the form on a page or post, copy the **Shortcode** from the top right and paste it into that page or post.

![Save Color Picker Field](/images/form-fields/advanced-fields/color-picker-field/Save-Form-05-5-scaled.webp)
