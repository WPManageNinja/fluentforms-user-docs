# Password Input Field

The **Password** field lets users enter secure passwords. It suits a [user registration form](/create-a-wordpress-user-registration-form).

This guide shows you how to add and customize the **Password** field in Fluent Forms.

## Adding Password Input Field

Go to **Forms** in the Fluent Forms navbar. Click the title of the form you want to edit to open the form editor.

> [!Note]
> If you have no forms yet, read [Create a Form from Scratch](/create-a-form) or [Create a Form using Templates](/using-and-customizing-pre-built-quick-forms).

![Editor](/images/form-fields/advanced-fields/password-input-field/form-editor-01-1-scaled.webp)

In the editor, click the **Plus Icon** and open the **Advanced Fields** module. You can also find **Advanced Fields** in the right sidebar under the **Input Fields** tab.

Click the **Password** field, or drag and drop it into your editor.

![Adding Password Field](/images/form-fields/advanced-fields/password-input-field/adding-password-field-02-scaled.webp)

## Customizing the Password Field

After you add the Password field, hover over it and click the **Pencil Icon**. The **Customize** tab opens on the right side with these options:

- Password Options

- Advanced Options

![Customize Fluent Forms](/images/form-fields/advanced-fields/password-input-field/input-customization-03-23-scaled.webp)

### Password Options

These options in the **Customize** tab configure the **Password** input field.

**A. Element Label:** The field title users see when they fill out the **Password input** field. Enter text that explains the field's purpose.

**B. Label Placement:** Set where the label appears. The options are **Default**, **Top**, **Right**, **Bottom**, **Left**, and **Hide Label**. **Default** uses your global label placement settings.

**C. Admin Field Label:** The admin field label is a title shown only to admins. Use it to show a different label when admins view form submissions.

**D. Placeholder:** Set the text shown while the field is empty, so users know what to enter. This is the HTML input placeholder attribute.

**E. Required:** Choose whether users can submit the form with this field empty.

![Password Input Options](/images/form-fields/advanced-fields/password-input-field/Password-input-options-04-scaled.webp)

### Advanced Options

Advanced settings let you adapt the field to specific use cases. The settings under **Advanced Options** are:

**A. Autocomplete:** Choose a value that tells the browser what the field collects, so it can offer saved details. Options are **Automatic**, **off**, **None**, or a specific value. Click the **Dropdown Arrow** to see all the options. To learn more, read [Autocomplete for Form Fields](/autocomplete-for-form-fields).

**B. Default Value:** Set a fixed value, or use shortcodes to pre-fill the field dynamically. Read the [Dynamic Default Value documentation](/dynamic-default-value) to learn more. You can also add values with the **Three-Dot** option.

**C. Container Class:** Add custom CSS classes to the field’s wrapper.

**D. Element Class:** Add custom CSS classes to the input field.

**E. Help Message:** Add text that appears as a help message for the user.

**F. Prefix Label:** Add a prefix text or symbol before the input area for extra context.

**G. Suffix Label:** Add a suffix text or symbol after the input area.

**H. Name Attribute:** The input field’s name attribute is the HTML equivalent of the same name. You do not need to change it.

**I. Conditional Logic:** Create rules that show or hide the field based on submission values. To learn more, read the [Conditional Logic documentation](/set-up-forms-with-conditional-logic).

![Password Advanced Option](/images/form-fields/advanced-fields/password-input-field/password-advanced-option-scaled.webp)

## Embed the Form into the Front

Click **Save** to keep your changes. Click the **Preview** (eye) icon at the top right to see the form preview.

To show the form on a page or post, copy the **Shortcode** from the top right and paste it into that page or post.

![Save Password Input Field](/images/form-fields/advanced-fields/password-input-field/Save-form-06-23-scaled.webp)
