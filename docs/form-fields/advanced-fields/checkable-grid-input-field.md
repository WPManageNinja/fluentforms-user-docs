# Checkable Grid Input Field

The **Checkable Grid** input field in [Fluent Forms](https://wordpress.org/plugins/fluentform) collects feedback, survey answers, assessments, and preferences. It works like a compact group of checkboxes or radio buttons. To learn more about single fields, see [Checkbox Field](/checkbox-field).

This guide shows you how to add and customize the **Checkable Grid Field** in Fluent Forms.

> [!Note]
> The **Checkable Grid** field requires **Fluent Forms Pro**. See [Upgrade to Fluent Forms Pro Add-on](/upgrade-to-pro-add-on).

## Adding Checkable Grid Field

Go to **Forms** in the Fluent Forms navbar. Click the title of the form you want to edit to open the form editor.

> [!Note]
> If you have no forms yet, read [Create a Form from Scratch](/create-a-form) or [Create a Form using Templates](/using-and-customizing-pre-built-quick-forms).

![Editor](/images/form-fields/advanced-fields/checkable-grid-input-field/editor-form-01-1-scaled.webp)

In the editor, click the **Plus Icon** and open the **Advanced Fields** module. You can also find **Advanced Fields** in the right sidebar under the **Input Fields** tab.

Click the **Checkable Grid** field, or drag and drop it into your editor.

![Adding Checkable Grid](/images/form-fields/advanced-fields/checkable-grid-input-field/adding-checkable-grid-02-scaled.webp)

## Customizing the Checkable Grid Field

After you add the checkable grid field, hover over it and click the **Pencil Icon**. The **Customize** tab opens on the right side with these options:

- Checkable Grid Options

- Advanced Options

![Customize Fluent Forms](/images/form-fields/advanced-fields/checkable-grid-input-field/input-customization-03-21-scaled.webp)

### Checkable Grid Options

These options in the **Customize** tab configure the **Checkable Grid** input field.

**A. Element Label:** The field title users see when they fill out the **Checkable Grid** field. Enter text that explains the field's purpose.

**B. Label Placement:** Set where the label appears. The options are **Default**, **Top**, **Right**, **Bottom**, **Left**, and **Hide Label**. **Default** uses your global label placement settings.

**C. Admin Field Label:** The admin field label is a title shown only to admins. Use it to show a different label when admins view form submissions.

**D. Field Type:** Set the grid to work as a **Checkbox** or a **Radio** button field. A checkbox allows multiple choices. A radio button allows a single choice.

**E. Grid Columns:** Add columns to your grid. Click the **Plus** (+) icon to add a column to the vertical grid.

Each click adds one column. Click the **Minus** (-) icon to delete a column.

You can customize the grid columns:

- **Selection:** Click the checkbox option to pre-select options.

- **Show Values:** Enable **Show Value** to add a value to each option. This helps admins.

- **Naming Options:** Set the column and row labels.

- **Rearrange Options:** Drag and drop the holding markers to rearrange the options.

**F. Grid Rows:** Add rows to your grid. Click the **Plus** (+) icon to add a row to the horizontal grid.

Each click adds one row. Click the **Minus** (-) icon to delete a row.

You can customize the grid rows:

- **Selection:** Click the checkbox option to pre-select options.

- **Show Values:** Enable **Show Value** to add a value to each option. This helps admins.

- **Naming Options:** Set the column and row labels.

- **Rearrange Options:** Drag and drop the holding markers to rearrange the options.

**G. Required:** Choose whether users can submit the form with this field empty.

![Checkable Grid](/images/form-fields/advanced-fields/checkable-grid-input-field/checkable-grid-04-scaled.webp)

### Advanced Options

Advanced settings let you adapt the field to specific use cases.

**A. Container Class:** Add custom CSS classes to the field’s wrapper.

**B. Help Message:** Add text that appears as a help message for the user.

**C. Name Attribute:** The input field’s name attribute is the HTML equivalent of the same name. You do not need to change it.

**D. Conditional Logic:** Create rules that show or hide the field based on submission values. To learn more, read the [Conditional Logic documentation](/set-up-forms-with-conditional-logic). 

![Advanced Options Fluent Forms](/images/form-fields/advanced-fields/checkable-grid-input-field/Advanced-options-05-16-scaled.webp)

## Embed the Form into the Front

Click **Save** to apply your changes.

To show the form on a page or post, copy the **Shortcode** from the top-right corner and paste it into that page or post.

To preview the form, click the **Preview** (eye) icon at the top right.
