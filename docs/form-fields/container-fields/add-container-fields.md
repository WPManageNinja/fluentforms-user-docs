# Add Container Fields

The **Container** field places multiple fields side by side in one row instead of a new row for each field. This makes your form more compact and organized. This article shows you how to add the **Container** field to your form.

> [!Note]
> Use the **Container** field to build compact **inline forms** that sit inside text, paragraphs, or other content without breaking your page layout. See [Inline Opt-in Form Using Fluent Forms](/inline-opt-in-form).

## Add Container Fields

Go to **Forms** in the Fluent Forms navbar. Click the title of the form you want to edit to open the form editor.

> [!Note]
> If you have no forms yet, read [Create a Form from Scratch](/create-a-form) or [Create a Form using Templates](/using-and-customizing-pre-built-quick-forms). For example, this guide uses an existing form to show the whole process.

![Open Container Fields](/images/form-fields/container-fields/add-container-fields/1.-Open-desired-form-6-scaled.webp)

In the editor, click the **Plus Icon** and open the **Container** module. You can also find **Container** in the right sidebar under the **Input Fields** tab.

The **Container** module offers **six types** of container fields. They work the same way and differ only in the number of columns. For collapsible sections, use the [Accordion Container](/add-accordion-container-fields). For repeatable sets of fields, use the [Repeat Container](/add-repeat-container-field).

Click the **Column Layout** you want, or drag and drop it into your editor. For example, select **Three Column Container**.

![Container Fields Three Column Container](/images/form-fields/container-fields/add-container-fields/2.-Container-Fields-Three-column-container-scaled.webp)

Click the **Plus Icon** in each column to add a field.

For example, add the **Name**, **Email**, and **Custom Submit Button** fields inside the three columns. To learn about each field, see [Name Input Field](/name-input-field).

![Plus Icon Add Fields](/images/form-fields/container-fields/add-container-fields/3.-Plus-Icon-to-add-fields-scaled.webp)

You can also drag and drop the **Name**, **Email**, and **Custom Submit Button** fields into the columns.

> [!Note]
> Adding a [Custom Submit Button](/custom-submit-button) to a container hides the form’s default **Submit** button. Only the custom button is shown.

![Entering Input Fields Columns Copy](/images/form-fields/container-fields/add-container-fields/4.-Entering-input-fields-in-columns-copy.gif)

Drag fields to adjust their position, as the GIF below shows.

![Adjusting Width Field](/images/form-fields/container-fields/add-container-fields/5.-Adjusting-the-width-of-the-field.gif)

## Customize Container Field

Hover over the **Container** field and click the **Pencil Icon**. The **Customize** tab opens on the right side with these options:

**A. Container Class:** Add custom CSS classes to the field’s wrapper.

**B. Conditional Logic:** Make the container field work conditionally based on your submission values. To learn more, read the [Conditional Logic documentation](/set-up-forms-with-conditional-logic).

**C. Column Width %:** Set the width of the columns. The minimum column width is 10%. You can also drag the column borders to resize them visually with the [Resizeable Container](/resizeable-container).

**D. Auto Width:** Click **Yes** to calculate column widths automatically. Click **No** to set the widths yourself.

![Container Customize](/images/form-fields/container-fields/add-container-fields/6.-Container-input-customization-scaled.webp)

To customize a field inside a column, hover over it and click the **Pencil Icon**. The **Customize** tab shows the options for that field.

> [!Tip]
> Match the form to your site design with the [Official Form Styler of Fluent Forms](/official-form-styler) or custom CSS in [Fluent Forms Styling/Custom CSS](/stylingcustom-css).

![Plencil Icon Customize Fields](/images/form-fields/container-fields/add-container-fields/7.-Plencil-Icon-to-customize-fields-scaled.webp)

## Embed the Form into Frontend

Click **Save** to keep your changes. Click the **Preview** (eye) icon at the top right to see the form preview.

To show the form on a page or post, copy the **Shortcode** from the top right and paste it into that page or post.
