# Add Repeat Container Field

The **Repeat Container** field lets users submit information through **one or more fields** repeatedly by duplicating them. You place multiple fields inside a single container, and users fill in multiple sets of data for those fields.

For example, use the **Repeat Container** field to let users submit multiple emails, phone numbers, and website URLs. Users add as many entries as they need by duplicating the fields with one click.

This article shows you how to add the **Repeat Container** field to your form.

> [!Note]
> **Repeat Container** requires **Fluent Forms Pro**. See [Upgrade to Fluent Forms Pro Add-on](/upgrade-to-pro-add-on).

> [!Note]

## Add Repeat Container Field

Go to **Forms** in the Fluent Forms navbar. Click the title of the form you want to edit to open the form editor.

> [!Note]
> If you have no forms yet, read [Create a Form from Scratch](/create-a-form) or [Create a Form using Templates](/using-and-customizing-pre-built-quick-forms).

![Edit Repeat Container Field](/images/form-fields/container-fields/add-repeat-container-field/edit-form-1-scaled.webp)

In the editor, click the **Plus Icon** and open the [Container](/add-container-fields) module. You can also find **Container** in the right sidebar under the **Input Fields** tab.

Click the **Repeat Container**, or drag and drop it into your editor.

>[!Note]
>Only specific field types can be used within the Repeater Container. For example, the standard Name field is not supported; use a **Simple Text** field instead for name inputs.

![Repeater Container Field](/images/form-fields/container-fields/add-repeat-container-field/repeater-container-field-2-scaled.webp)

## Customize Repeat Container Field

Hover over the **Repeat Container** field and click the **Pencil Icon**. The **Customize** tab opens on the right side with these options:

1. Repeat Container

2. Advanced Options

![Customize](/images/form-fields/container-fields/add-repeat-container-field/input-customization-3-scaled.webp)

### 1. Repeat Container

Configure labels, columns, and width from the **Customize** tab:

**A. Element Label:** The field title users see when they fill out the **Repeat Container** field. Enter text that explains the purpose of the field.

**B. Label Placement:** Set where the label appears. The options are **Top**, **Right**, **Bottom**, **Left**, **Hide Label**, and **Default**. **Default** uses your global label placement settings.

**C. Admin Field Label:** The admin field label is a title shown only to admins. Use it to show a different label when admins view form submissions.

**D. Container Columns:** Select the number of columns for your Repeat Container field. Each column works the same way. For example, this guide uses 3 columns.

**E. Column Width %:** Set the width of the columns. The minimum column width is 10%.

**F. Auto Width:** Click **Yes** to calculate column widths automatically. Click **No** to set the widths yourself.

![Repeat Container](/images/form-fields/container-fields/add-repeat-container-field/repeat-container-4-scaled.webp)

### 2. Advanced Options

Advanced settings let you adapt the field to specific use cases.

**A. Container Class:** Add custom CSS classes to the field’s wrapper.

**B. Name Attribute:** The input field’s name attribute is the HTML equivalent of the same name. You do not need to change it.

**C. Conditional Logic:** Make the **Repeat Container** field run only when your conditions match. To learn more, see [Set Up Forms With Conditional Logic in Fluent Forms](/set-up-forms-with-conditional-logic).

**D. Max Repeat inputs:** Set the maximum number of times users can duplicate the fields within the Repeat Container. To total numeric values entered across the repeated rows, see [How to Add Calc Values on the Repeat Field](/add-calc-values-on-the-repeat-field).

![Advanced Fluent Forms](/images/form-fields/container-fields/add-repeat-container-field/advanced-5-scaled.webp)

Click the **Plus Icon** to add a field in each of the three columns. You can drag fields to adjust their position.

To customize a field inside a column, hover over it and click the **Pencil Icon**. The **Customize** tab shows the options for that field.

![Container Field](/images/form-fields/container-fields/add-repeat-container-field/container-field-6-scaled.webp)

## Embed the Form into Frontend

Click **Save** to keep your changes. Click the **Preview** button in the middle to see the form preview.

To show the form on a page or post, copy the **Shortcode** from the top right and paste it into that page or post.

![Save Repeat Container Field](/images/form-fields/container-fields/add-repeat-container-field/save-form-7-scaled.webp)
