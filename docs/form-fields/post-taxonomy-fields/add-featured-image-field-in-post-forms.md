# Add Featured Image Field in Post Forms

The **Featured Image** field lets users submit a media file for their post. This article shows you how to add the **Featured Image** field to your form.

> [!Note]
> This field is a Pro feature. It appears in the editor only when the **Post/CPT Creation** module is enabled. See [Create a Post Form](/create-a-post-form).

## Add Featured Image Field

Go to **Forms** in the Fluent Forms navbar. Click the title of your **Post Form** to open the form editor.

![Open Post Featured Image Field in](/images/form-fields/post-taxonomy-fields/add-featured-image-field-in-post-forms/1.-Open-desired-Post-form-3-scaled.webp)

In the editor, go to **Input Fields** in the right sidebar. Click the **Arrow Icon** to open the **Post Fields** dropdown list. Click the **Featured Image** field, or drag and drop it into your editor.

![Add Featured Field](/images/form-fields/post-taxonomy-fields/add-featured-image-field-in-post-forms/2.-Add-Featured-Image-field-scaled.webp)

## Customize Featured Image Field

Hover over the **Featured Image** field and click the **Pencil Icon**. The **Customize** tab opens on the right side with these options:

1. Featured Image

2. Advanced Options

![Customize](/images/form-fields/post-taxonomy-fields/add-featured-image-field-in-post-forms/3.-Input-Customization-5-scaled.webp)

### 1. Featured Image

Configure **Featured Image** labels and upload options:

**A. Element Label:** The field title users see when they fill out the **Featured Image** field. Enter text that explains the purpose of the field.

**B. Admin Field Label:** The admin field label is a title shown only to admins. Use it to show a different label when admins view form submissions.

**C. Button Text:** The text shown on the upload button.

**D. Placeholder:** Set the text shown while the field is empty, so users know what to enter. This is the HTML input placeholder attribute.

**E. Default Value:** Set a default value to pre-populate the field. You can also set the value with **SmartCodes**. To learn more, read [Form Editor Smart Codes](/form-editor-smart-codes).

**F. Label Placement:** Set where the label appears. The options are **Top**, **Right**, **Bottom**, **Left**, **Hide Label**, and **Default**. **Default** uses your global label placement settings.

**G. Required:** Select the **Yes** radio button to make this field mandatory for a successful submission. Select **No** to make it optional.

**H. Max File Size:** Set the maximum file size a user can upload. You can also enable the **Global Error Message** option and enter a message that shows to users when an error occurs.

**I. Max Files Count:** Set the maximum number of files a user can upload. You can also enable the **Global Error Message** option and enter a message that shows to users when an error occurs.

**J. Allowed Images:** Select the formats users can upload.

![Featured Option Fluent Forms](/images/form-fields/post-taxonomy-fields/add-featured-image-field-in-post-forms/4.-Featured-Image-option.webp)

### 2. Advanced Options

Configure **Advanced** options:

**A. Name Attribute:** The input field’s name attribute is the HTML equivalent of the same name. You do not need to change it.

**B. Help Message:** Add text that appears as a help message for the user.

**C. Container Class:** Add custom CSS classes to the field’s wrapper.

**D. Element Class:** Add custom CSS classes to the input field itself. Use it to add custom CSS or JS for a specific input field.

**E. Conditional Logic:** Make the Featured Image field work conditionally based on your submission values. To learn more, read the [Conditional Logic documentation](/set-up-forms-with-conditional-logic).

![Advanced Options](/images/form-fields/post-taxonomy-fields/add-featured-image-field-in-post-forms/5.-Advanced-Options-6-scaled.webp)

## Configure Post Feed Settings

Configure the **Post Feed**. This step is **mandatory** to make your **Post Form** work. The feed maps your post fields for data collection and lets users create more customized posts.

> [!Note]
> Use the **Post Feed** settings to map your post fields, then save the feed. For the full workflow, see [How to Create a Post Form with Fluent Forms](/create-a-post-form).

## Embed the Form into Frontend

To show the form on a page or post, copy the **Shortcode** from the top right and paste it into that page or post.

Click **Save** to keep your changes. Click the **Preview** (eye) icon at the top right to see the form preview.
