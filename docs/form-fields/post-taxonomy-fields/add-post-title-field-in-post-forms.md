# Add Post Title Field in Post Forms

The **Post Title** field lets users submit a title for their post. This article shows you how to add the **Post Title** field to your form.

> [!Note]
> This field is a Pro feature. It appears in the editor only when the **Post/CPT Creation** module is enabled. See [Create a Post Form](/create-a-post-form).

## Add Post Title Field

Go to **Forms** in the Fluent Forms navbar. Click the title of your **Post Form** to open the form editor.

![Open Post Fluent Forms](/images/form-fields/post-taxonomy-fields/add-post-title-field-in-post-forms/1.-Open-desired-Post-form-scaled.webp)

In the editor, go to **Input Fields** in the right sidebar. Click the **Arrow Icon** to open the **Post Fields** dropdown list. Click the **Post Title** field, or drag and drop it into your editor.

![Add Post Title Field](/images/form-fields/post-taxonomy-fields/add-post-title-field-in-post-forms/2.-Add-Post-Title-field-scaled.webp)

## Customize Post Title Field

Hover over the **Post Title** field and click the **Pencil Icon**. The **Customize** tab opens on the right side with these options:

1. Post Title

2. Advanced Options

![Customize](/images/form-fields/post-taxonomy-fields/add-post-title-field-in-post-forms/3.-Input-Customization-2-scaled.webp)

### 1. Post Title

Configure **Post Title** labels and field behavior:

**A. Element Label:** The field title users see when they fill out the **Post Title** field. Enter text that explains the purpose of the field.

**B. Admin Field Label:** The admin field label is a title shown only to admins. Use it to show a different label when admins view form submissions.

**C. Placeholder:** Set the text shown while the field is empty, so users know what to enter. This is the HTML input placeholder attribute.

**D.** **Default Value:** Set a default value to pre-populate the field. You can also set the value with **SmartCodes**. To learn more, read [Form Editor Smart Codes](/form-editor-smart-codes).

**E. Label Placement:** Set where the label appears. The options are **Top**, **Right**, **Bottom**, **Left**, **Hide Label**, and **Default**. **Default** uses your global label placement settings.

**F. Required:** Select the **Yes** radio button to make this field mandatory for a successful submission. Select **No** to make it optional.

![Post Tilte Option](/images/form-fields/post-taxonomy-fields/add-post-title-field-in-post-forms/4.-Post-Tilte-option-scaled.webp)

### 2. Advanced Options

Configure **Advanced** options:

**A. Name Attribute:** The input field’s name attribute is the HTML equivalent of the same name. You do not need to change it.

**B. Help Message:** Add text that appears as a help message for the user.

**C. Container Class:** Add custom CSS classes to the field’s wrapper.

**D. Element Class:** Add custom CSS classes to the input field itself. Use it to add custom CSS or JS for a specific input field.

**E. Conditional Logic:** Make the Post Title field work conditionally based on your submission values. To learn more, read the [Conditional Logic documentation](/set-up-forms-with-conditional-logic).

![Advanced Option Fluent Forms](/images/form-fields/post-taxonomy-fields/add-post-title-field-in-post-forms/5.-Advanced-option-scaled.webp)

## Configure Post Feed Settings

Configure the **Post Feed**. This step is **mandatory** to make your **Post Form** work. The feed maps your post fields for data collection and lets users create more customized posts.

> [!Note]
> Use the **Post Feed** settings to map your post fields, then save the feed. For the full workflow, see [How to Create a Post Form with Fluent Forms](/create-a-post-form).

## Embed the Form into Frontend

To show the form on a page or post, copy the **Shortcode** from the top right and paste it into that page or post.

Click **Save** to keep your changes. Click the **Preview** (eye) icon at the top right to see the form preview.

![Save Post Title Field in](/images/form-fields/post-taxonomy-fields/add-post-title-field-in-post-forms/6.-Save-Form-1-scaled.webp)
