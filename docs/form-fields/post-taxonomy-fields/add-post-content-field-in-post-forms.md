# Add Post Content Field in Post Forms

The **Post Content** field lets users submit content for their posts. This article shows you how to add the **Post Content** field to your form.

> [!Note]
> This field is a Pro feature. It appears in the editor only when the **Post/CPT Creation** module is enabled. See [Create a Post Form](/create-a-post-form).

## Add Post Content Field

Go to **Forms** in the Fluent Forms navbar. Click the title of your **Post Form** to open the form editor.

![Open Post](/images/form-fields/post-taxonomy-fields/add-post-content-field-in-post-forms/1.-Open-desired-Post-form-1-scaled.webp)

In the editor, go to **Input Fields** in the right sidebar. Click the **Arrow Icon** to open the **Post Fields** dropdown list. Click the **Post Content** field, or drag and drop it into your editor.

![Add Post Content](/images/form-fields/post-taxonomy-fields/add-post-content-field-in-post-forms/2.-Add-Post-Content-scaled.webp)

## Customize Post Content Field

Hover over the **Post Content** field and click the **Pencil Icon**. The **Customize** tab opens on the right side with these options:

1. Post Content

2. Advanced Options

![Customize](/images/form-fields/post-taxonomy-fields/add-post-content-field-in-post-forms/3.-Input-Customization-3-scaled.webp)

### 1. Post Content

Configure **Post Content** labels and editor options:

**A. Element Label:** The field title users see when they fill out the **Post Content** field. Enter text that explains the purpose of the field.

**B. Label Placement:** Set where the label appears. The options are **Top**, **Right**, **Bottom**, **Left**, **Hide Label**, and **Default**. **Default** uses your global label placement settings.

**C. Admin Field Label:** The admin field label is a title shown only to admins. Use it to show a different label when admins view form submissions.

**D. Placeholder:** Set the text shown while the field is empty, so users know what to enter. This is the HTML input placeholder attribute.

**E. Rows:** Set the **number of rows** the **Textarea** field occupies in the form. This is an HTML attribute used for browser support.

**F. Columns:** Set the **number of columns** the **Textarea** field occupies in the form. This is an HTML attribute used for browser support.

**G. Required:** Select the **Yes** radio button to make this field mandatory for a successful submission. Select **No** to make it optional.

![Post Content Option](/images/form-fields/post-taxonomy-fields/add-post-content-field-in-post-forms/4.-Post-Content-option-scaled.webp)

### 2. Advanced Options

Configure **Advanced Options**:

**A. Default Value:** Set a default value to pre-populate the field. You can also set the value with **SmartCodes**. To learn more, read [Form Editor Smart Codes](/form-editor-smart-codes).

**B. Container Class:** Add custom CSS classes to the field’s wrapper.

**C. Element Class:** Add custom CSS classes to the input field itself. Use it to add custom CSS or JS for a specific input field.

**D. Help Message:** Add text that appears as a help message for the user.

**E. Name Attribute:** The input field’s name attribute is the HTML equivalent of the same name. You do not need to change it.

**F. Max text length:** Set the **maximum number of characters** the **Textarea** field accepts.

**G. Conditional Logic:** Make the Post Content field work conditionally based on your submission values. To learn more, read the [Conditional Logic documentation](/set-up-forms-with-conditional-logic).

![Advanced Options](/images/form-fields/post-taxonomy-fields/add-post-content-field-in-post-forms/5.-Advanced-Options-4-scaled.webp)

## Configure Post Feed Settings

Configure the **Post Feed**. This step is **mandatory** to make your **Post Form** work. The feed maps your post fields for data collection and lets users create more customized posts.

> [!Note]
> Use the **Post Feed** settings to map your post fields, then save the feed. For the full workflow, see [How to Create a Post Form with Fluent Forms](/create-a-post-form).

## Embed the Form into Frontend

To show the form on a page or post, copy the **Shortcode** from the top right and paste it into that page or post.

Click **Save** to keep your changes. Click the **Preview** (eye) icon at the top right to see the form preview.
