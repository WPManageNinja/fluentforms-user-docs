# Advanced & Developer Features in Fluent Forms

Ready to push your forms further? **Fluent Forms** gives power users and developers the tools to customize, extend, and fine-tune every detail — from dynamic shortcodes and custom fields to detailed logs and full translation support. This page rounds up the advanced capabilities and links you to each guide.

## Shortcodes & Smart Codes

Insert dynamic data anywhere. Use shortcodes and smart codes to personalize forms, emails, and confirmations on the fly.

- [Shortcodes Overview](/docs/fluent-forms-shortcodes-overview) — learn how Fluent Forms shortcodes work.
- [Helper Shortcodes](/docs/using-helper-shortcodes-in-fluent-forms) — pull in user, post, and submission data.
- [Conditional Shortcodes](/docs/conditional-shortcodes-in-fluent-forms) — show content based on conditions.
- [Smart Codes](/docs/form-editor-smart-codes) — insert dynamic values inside the form editor.
- [Pre-Fill from FluentCRM](/docs/pre-fill-form-fields-with-fluentcrm-data) — auto-fill fields with FluentCRM data.

## Custom Fields & Meta

Connect to your data model. Map form input to custom fields and meta keys across popular frameworks.

- [Meta Box](/docs/how-to-use-meta-box-custom-fields-with-fluent-forms) — save submissions to Meta Box custom fields.
- [Mapping Meta Fields](/docs/mapping-meta-fields-with-meta-keys-in-fluent-forms) — link form fields to custom meta keys.
- [ACF Custom Fields](/docs/use-acf-to-add-a-custom-field-in-the-post-form) — use Advanced Custom Fields in post forms.
- [JetEngine](/docs/using-jetengine-custom-fields-with-fluent-forms) — work with JetEngine custom fields.
