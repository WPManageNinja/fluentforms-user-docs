# Advanced & Developer Features

**Fluent Forms** gives power users and developers tools to customize and extend forms, from dynamic shortcodes and custom fields to detailed logs and translation support. This page lists the advanced capabilities and links you to each guide.

## Shortcodes & Smart Codes

Insert dynamic data anywhere. Use shortcodes and smart codes to personalize forms, emails, and confirmations on the fly.

- [Shortcodes Overview](/shortcodes-overview) — see every shortcode and smart code group.
- [Helper Shortcodes](/using-helper-shortcodes) — show submission counts, entry details, and payment statuses anywhere on your site.
- [Conditional Shortcodes](/conditional-shortcodes) — show or hide content in confirmations, emails, and PDFs based on user selections.
- [Smart Codes](/form-editor-smart-codes) — set default input values from your website, user, post, and FluentCRM data.
- [Shortcodes in Confirmation Settings](/shortcodes-in-confirmation-settings) — show submitted data in confirmations, emails, PDFs, and quiz results.
- [Pre-Fill from FluentCRM](/pre-fill-form-fields-with-fluentcrm-data) — auto-fill fields with FluentCRM data.

## Custom Fields & Meta

Connect to your data model. Map form input to custom fields and meta keys across popular frameworks.

- [Meta Box](/use-meta-box-custom-fields) — save submissions to Meta Box custom fields.
- [Mapping Meta Fields](/mapping-meta-fields-with-meta-keys) — map post meta fields in Post Forms and Product Forms.
- [ACF Custom Fields](/use-acf-to-add-a-custom-field-in-the-post-form) — use Advanced Custom Fields in post forms.
- [JetEngine](/using-jetengine-custom-fields) — create and map JetEngine custom fields in Post Forms.

## Logs, Tracking & Utilities

Stay in control. Monitor activity, track conversions, and find anything fast.

- [API Logs](/api-logs) — review outgoing API requests and responses.
- [Activity Logs](/activity-logs) — see a record of actions on your forms.
- [Event Tracking (GA4)](/event-tracking-with-google-analytics-ga4-via-google-tag-manager) — track form events in Google Analytics 4.
- [Global Search](/global-search) — find forms, settings, and help articles from one place.
- [Phone Geo-Location (Pro)](/phone-field-geo-location-provider) — detect a user's country in phone fields with a geo-location provider.

## Localization

Speak your users' language. Translate forms and fields for a global audience.

- [Translate with WPML](/translate-forms-with-wpml) — make your forms multilingual with WPML.
- [Translate Datepicker](/translate-datepicker-field) — localize the date picker field.
