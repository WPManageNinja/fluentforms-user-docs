# Design a Conversational Form

**Fluent Forms** gives you several options to customize the look and behavior of **Conversational Forms**. This guide shows you how to style the form, edit its messages, and share it.

## Designing Conversational Forms

Click **Forms** in the top bar, then click the title of the conversational form you want to design.

> [!Note]
> If you do not have an existing conversational form, see [How to Create a Conversational Form](/create-a-conversational-form).

![Edit conversational form](/images/creating-forms/conversational-forms/design-a-conversational-form/1.-Open-desired-form-Editor-scaled.webp)

On the **Editor** page, click **Appearance** in the top bar. The right panel shows three tabs:

1. Elements
2. Form Messages
3. Behavior

The live preview appears on the left. Use the device icons above it to check desktop, tablet, and mobile layouts.

![Design Meta Share tabs](/images/creating-forms/conversational-forms/design-a-conversational-form/Conversational-Form-Design-FluentForm-04-22-2025_03_34_PM-scaled.webp)

### 1. Elements

The **Elements** tab styles each part of the form:

 * **Style Preset:** Pick a ready-made look, such as **Clear Blue**, **Forest**, **Plum**, **Night**, **Reef**, or **Spark**. Use the **Custom** options below to fine-tune it.
 * **Questions:** Choose the color of the questions.
 * **Answers:** Choose the color of the answers.
 * **Background:** Choose a background image or color. For an image, you can also adjust the background brightness.
 * **Accent:** Choose the accent background and text colors, which style the button.
 * **Font:** Choose a font family for the form.

Click **Save** in the top bar to save your changes.

![Conversational form design](/images/creating-forms/conversational-forms/design-a-conversational-form/2.-Design-tab-scaled.webp)

### 2. Form Messages

The **Form Messages** tab sets the text your visitors see while they fill out the form:

 * **Continue Button Text:** Set the text of the Continue button.
 * **Skip Button Text:** Set the text of the Skip button.
 * **Keyboard instruction to go to the next question:** Add an instruction that tells users how to move to the next question.
 * **Hint for making a line break in Textarea:** Add a hint that tells users how to make a line break in a Textarea.
 * **Hint for multiple selections:** Add a hint that tells users they can select multiple options.
 * **Key Hint Label:** Add a key hint label.
 * **Confirm Button Text:** Set the text of the Confirm button. The default is "OK".
 * **Hint for Single Selection:** Add a hint that tells users they can select one option.
 * **Progress Text:** Set the progress text. The available variables are {percent}, {step}, and {total}.
 * **Invalid Input Message:** Set the message users see when they fill a field incorrectly.
 * **Default Placeholder:** Set the default placeholder text for fields.
 * **Key Hint Tooltip:** Set the key hint tooltip text.
 * **File Size Limit Label:** Describe the recommended file upload size limit.

Click **Save** in the top bar to save your changes.

![Conversational form meta](/images/creating-forms/conversational-forms/design-a-conversational-form/3.-Meta-tab.webp)

### 3. Behavior

The **Behavior** tab controls how the conversational form works. Turn each option on or off:

 * **Disable Layout on Mobile Devices:** Fall back to a standard form on phones.
 * **Disable Scroll to Next:** Require a click instead of auto-advancing to the next question.
 * **Enable Scroll to Top:** Jump back to the top each time a new question opens.
 * **Keyboard hints:** Show the **Press Enter** hint next to the button.
 * **Disable branding:** Hide the **Powered by** footer credit.

![Conversational form behavior](/images/creating-forms/conversational-forms/design-a-conversational-form/behavior.webp)

### Share the Form

To share your form, go to **Configuration** in the top bar and open **Share & Embed** under **Sharing & Meta**. You can share the form by a unique URL (Pro), or embed it with a shortcode in a page or post. The options are:

 * **Share Via Direct URL (Pro):** Get the link or share it on social sites.
 * **Shortcode for Conversational Form:** Paste the shortcode into a Page or Post.
 * **Shortcode for Classic Form:** Use this shortcode to show the classic version of the form.
 * **Embed via HTML Code:** Use this code to show the form on another domain, another site, or outside WordPress. You can customize the height property.

![Share conversational form](/images/creating-forms/conversational-forms/design-a-conversational-form/4.-Share-tab-scaled.webp)

Click **Save** in the top right corner to save your changes.

Click the **Preview** (eye) icon to preview your form. To display the form on the front end, click the copy icon next to the shortcode in the top bar.

![Save and shortcode](/images/creating-forms/conversational-forms/design-a-conversational-form/5.-Save-form-button-scaled.webp)
